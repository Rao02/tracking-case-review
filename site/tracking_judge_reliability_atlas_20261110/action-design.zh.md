# 具身跟踪诊断指标：来源、定义与现有证据

这是一套基于现有测试的本地适配分析，不是对 GridWM-Judge 的协议复现，也不宣称指标首创。先固定可解释的定义，再统一分析所有模型；不能根据某模型结果挑指标或改阈值。新增网络调用仅来自用户授权的第三类模型补齐，与此离线分析分离。

## 研究主线

研究模型能否把目标、相机运动、图像时序、WP及动作后果维持为可互相核对的状态表征；分别检查基础理解、信息条件变化以及有限反馈后的决策行为。当前证据不能证明模型内部存在某种统一表征或自我纠错机制。第一、二类给出信息与问答诊断；第三类给出原生动作后果和有限分支反馈诊断，不代表实时闭环tracking效果。

特别纠正：当前第三类A实际要求从S0/S1/S2重建已观察到的两段动作，不是从四条可行路径中寻找最优跟踪策略。B要求从当前图和候选动作匹配候选结果图；C才是看当前状态、选动作、接收中间状态再继续。A是逆向动作对应，B是受限候选集的正向动作对应，C是有限反馈决策。

## 现有数据的重点指标

### 1. 稳定错误及错误身份

以同一条件三次完整回答为单位：H0三次全错、H3三次全对、H1+H2混合正确。进一步统计W_same：三次全部错且语义归一化答案完全相同。H0并不保证错误内容相同。连续框和WP需先规定容差或报成对距离，不能只比较JSON字符串。三答不是三个独立episode，也不能认证上游采样独立性。

排序另报成员集合、端到端成对顺序分及完全倒序。题面指定候选集合时，成员得分是范围遵从，不冒称独立证据筛选能力。

### 2. 引导收益与误导代价

在同事件、同effort、同题面/图像、相同请求配置及可比较route中，令p0为无辅助三答均值，pg为某辅助条件的三答均值。报告均值差、事件层max(pg-p0,0)与max(p0-pg,0)的分布，连同按episode聚类的区间及三答噪声敏感性。增益与损失是描述性分解，不能称同一次推理的纠错或因果翻转。真假引导均可能提升答分；这需要分析模型是否跟随具体错误事实，不能据此直接断言抵抗误导。

更有意义的局部指标是错误建议采纳率：只在错误建议明确对应某个可验证选项/事实、且与gold冲突的题目中，统计模型回答是否采用该建议。逐题先标定建议到答案的映射，不凭词语相似度打分，未标定的不计算。

### 3. 同一事实保持与历史敏感性

第二类只在同一目标、同一图片、同一坐标/时间定义且原子gold不变的字段上计算：先对后错、先错后对、始终对、始终错；各自给入口覆盖和条件率。不能把easy到hard整题正确性的改变称为事实翻转。已有身体框配对可先做，其他题型需做语义匹配审核。

历史敏感性分析固定第三问、当前引导、effort和事件，比较前两问不同辅助历史下第三问的字段得分与答案分布。完整4^3设计能支持这项分析，但模型前两轮自生成答案属于历史处理的一部分。不能将差异直接归因为记忆、CoT或唯一的辅助机制。最大最小差会因有限样本膨胀，应附episode聚类bootstrap和历史标签置换诊断。若与独立问答比较，必须使用共同事件、同最终问题、同当前引导和实际high配置。

### 4. 正向/逆向动作对应的一致性与扎实程度

已逐题核对300组A/B：同一阶段，四个选项图的label和SHA一致；A参考末图恰好等于B中gold参考动作的结果图。令a*为A参考动作，o*为该参考末图，a_hat为模型A答案，f_hat为模型B配对。

- 跨协议一致性K = P(f_hat(a_hat)=o*)。它允许两处错误相互吻合。
- 扎实的联合对应G = P(a_hat=a* 且 f_hat(a*)=o*)。
- 错误但一致U = P(a_hat不等于a* 且 f_hat(a_hat)=o*)。K=G+U。
- 并列四象限：A对/B参考动作后果对、A对/后果错、A错/后果对、两者都错。

每个条件使用A三答与B三答的全部3x3组合后先求条件均值。9个组合不是9个独立样本，更不是同一次会话的内部一致性。G/B单项不是全双射正确率，不能混用。结果属于不同输入负担下的互补能力对应，不是因果缺陷定位。Grok只纳入三答均齐的配对条件，并报告覆盖，不与完整模型直接排名。

### 5. 瑕疵制造、补救与错误累积

沿用已冻结的C/D/X角色：C为参考，D为可补救瑕疵，X为失败动作。成功路径为CC、DC、CDC。

- 首步瑕疵率 = n(D*)/N；首步X率和格式停止率单列。
- 瑕疵后补救率 = n(DC)/n(D*)，并报联合补救覆盖n(DC)/N。
- 重复瑕疵率 = n(DD)/n(D*)。D之后再次D按任务预算失败，不称物理上永久不可恢复。
- 参考后退化率 = n(CD*)/n(C*)；之后补救率 = n(CDC)/n(CD*)。
- 无需补救的完成率 = n(CC)/N。
- 成功中经过补救的比例 = [n(DC)+n(CDC)]/[n(CC)+n(DC)+n(CDC)]。

最后一项表示成功对补救分支的依赖程度，不是越高越好。不能将早失败的少步数算高效率。各模型实际进入D或CD的事件分布不同，条件补救率不能当成相同状态的纯恢复能力对比；未来可另冻结少量强制同状态探针。

### 6. 有物理单位的代价向量（下一步离线提取）

从已保存完整原生执行trace计算：目标可见时间比例、距离超出协议区间的时间积分（m*s）、绝对朝向超界积分（rad*s）、遮挡/错误目标暴露、成功路径的真实模拟动作时间。时间权重来自sim time；API耗时单列。门槛沿用冻结PROTOCOL，而非按模型结果调参。CC与DC即使两次选择后都成功，也可能具有不同中间观测损失。先报代价向量与Pareto关系，不手调权重制造“tracking智能总分”；暂不把这些局部诊断称官方SR/TR/CR。

### 7. 可见解释与动作后果是否一致（需补注释）

利用C已有observed_evidence、expected_consequence、recovery_reason以及A/B简短reason，只核验可见文本。把解释拆成目标身份、可见性、机器人旋转、相对位移及动作后果等原子事实，对照当前图/相机姿态/原生执行trace。报告：选项对但事实解释错；选项错但部分物理描述对；宣称能恢复而该分支实际上越界。先盲标一部分并冻结事实字典及评分规则，再统一全模型统计；暂不把解释流畅度计为理解能力，不推断隐藏思维链。

## 已完成的离线最小验证

`analyze.py`和`RESULTS.json`包含五个模型的第三类新诊断。原始回答取独立快照，统一采用既有唯一JSON正文提取器做A/B内容诊断；C严格尊重当时实际终止和访问分支，不事后补造后续。DPSK采用原完整283会话加本次14次完整补测的预定合并，排除后来原队列的重复完成。

这次检查也验证B的300题涵盖全部24种排列；固定A->1,B->2,C->3,D->4整题仅5.67%，最常见固定排列7.33%。随机全排列的整题机会率为4.17%，逐项为25%。该检查排除“标准答案全部按顺序”的现成捷径，但不替代真正的动作遮蔽对照。

结果不含新模型测试，不修改gold，不产生显著性或首创宣称。论文主表建议保留基础能力、信息敏感性、稳定性、动作一致性和分支恢复五个面板，避免将所有诊断拼成一项排名。

## 下一步统计顺序

1. 三模型第三类补缺在隔离队列执行；历史原答案保留。
2. 五个已具备结果模型先取共同题目覆盖，按STT/DT/AT、题型、选项难度、来源、route和实际参数分层。
3. 条件/阶段/三答在event内汇总，主置信区间按episode family重采样；场景聚类作为敏感性分析。所有条件指标同时报入口覆盖，指标分母不可隐藏。
4. 明确探索性、多重比较及共同覆盖筛选，不把三次采样当新增场景；模型差异只在有聚类区间支持时称统计显著。
5. 最优先新增的机制验证是小规模B动作遮蔽/打乱、C同状态探针，随后才考虑Full/CF二元judge题。它们需单独授权和冻结，不混入正在补答的原测试题。
